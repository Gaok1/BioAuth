## Status

| WEB-02 | P0 | ✅ | `install.ps1` registra e remove o host por usuário em HKCU para Chrome, Edge e Firefox. `install.sh` instala e remove os manifests nos três caminhos Linux documentados. Ambos geram manifests específicos por navegador com caminho absoluto para o executável e allowlist da extensão correspondente. |

## Uso

Windows (PowerShell):

```powershell
desktop/browser-extension/native-host/install.ps1 -HostPath desktop/target/release/phone-auth-webauthn-host.exe -ChromeExtensionId <id> -EdgeExtensionId <id>
desktop/browser-extension/native-host/install.ps1 -Action Uninstall
```

Linux:

```bash
desktop/browser-extension/native-host/install.sh install --host desktop/target/release/phone-auth-webauthn-host --chrome-extension-id <id> --edge-extension-id <id>
desktop/browser-extension/native-host/install.sh uninstall
```

Use `-Browsers Firefox` no Windows ou `--browsers firefox` no Linux para instalar somente o Firefox sem informar IDs Chromium. O ID Firefox padrão é o ID fixo do manifesto da extensão, `webauthn@bioauth.local`.

## Verificação

```powershell
desktop/browser-extension/native-host/install.test.ps1
& 'C:\Program Files\Git\bin\bash.exe' desktop/browser-extension/native-host/install.test.sh
```

Os testes instalam em HOME, diretório de manifests e raiz HKCU temporários, conferem caminho absoluto e allowlists, executam a desinstalação e provam que manifests e chaves foram removidos.
